# Bot de Noticias via WhatsApp 

## Resumo da Automação Proposta

Este projeto consiste em um **Bot de WhatsApp** desenvolvido em Python, projetado para atuar como um assistente inteligente de busca e curadoria de notícias. 

**O Problema:** Diariamente, somos bombardeados por um grande volume de informações sem filtro, o que gera fadiga, atrapalha a concentração e consome muito tempo. Até mesmo motores de busca tradicionais, como o Google, podem sobrecarregar o usuário com excesso de resultados.

**A Solução:** O bot automatiza o processo de consulta a informações de forma simples e direta. O usuário solicita notícias sobre um determinado tema diretamente pelo WhatsApp. Integrado a uma API de LLM (Inteligência Artificial), o sistema realiza a pesquisa, filtra o conteúdo e retorna as **3 principais notícias** sobre o tópico, acompanhadas de um breve resumo (sintaxe) e os respectivos links das fontes originais.

**Como funciona o fluxo:**
1. O usuário envia uma mensagem no chat do WhatsApp pedindo informações sobre um tema 'X'.
2. O Bot compreende a solicitação.
3. A IA busca e filtra as notícias mais relevantes.
4. A IA gera um resumo automático (sintaxe) e extrai os links das matérias completas.
5. O Bot entrega o conteúdo final formatado e direto no WhatsApp do usuário.

## Tecnologias e Ferramentas Utilizadas

* **Python**: Linguagem principal para construção da lógica do sistema e integração.
* **WhatsApp Business Cloud API**: Para a comunicação, recebimento e envio de mensagens pelo aplicativo.
* **API de LLM (A decidir)**: Motor de inteligência artificial responsável por buscar, interpretar, filtrar e resumir as notícias.
